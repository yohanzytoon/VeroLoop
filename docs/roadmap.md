# Roadmap

- **Version 0.1:** multi-provider task evaluation, canonical structured output, deterministic
  metrics, stability, console/JSON/MLflow.
- **Version 0.2:** Azure OpenAI and Bedrock, model-specific schema compilation, explicit fallbacks,
  richer costs, caching, and resumability.
- **Version 0.3:** baseline snapshots, frozen temporal and tool/retrieval replay, perturbation tests,
  pytest helpers, and CI gates.
- **Version 0.4:** prompt/model/schema/parameter tuning, provider-aware prompt profiles,
  multi-objective optimization, and active case selection.
- **Version 0.5+:** tools, retrieval, LangGraph, failure clustering, component attribution, and
  hosted collaboration/governance.
